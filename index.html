How To Host & Share Your Link

Step-by-step guide to put this online for free

Free Public URL with GitHub Pages
  1. Save this webpage code onto your computer as a file named index.html.
  2. Go to GitHub.com and create a new public repository named yourusername.github.io.
  3. Upload your index.html file directly into the repository.
  4. Go to Settings > Pages, select main branch, and hit Save.

✨ Your site will be live at: https://yourusername.github.io

Drag-and-Drop Instant Host
  1. Save this code into a folder on your computer as index.html.
  2. Open Netlify Drop in your web browser.
  3. Drag and drop the folder containing your file right into the drop zone on the page.
  4. Netlify instantly generates a public live link for you to put in your bio!
Deploying via Vercel
  1. Push your code to GitHub or create a local project folder.
  2. Go to Vercel.com and click Add New Project.
  3. Import your GitHub repo or use vercel deploy from terminal.
  4. Click Deploy to receive a fast global HTTPS domain.
